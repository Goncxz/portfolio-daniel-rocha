# Portfólio — Daniel Rocha Gonçalves

Esta pasta contém a versão atual do portfólio, feita apenas com HTML, CSS e JavaScript.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: layout, cores e estilos responsivos.
- `script.js`: menu, destaque da seção ativa e seleção dos serviços.

## Como visualizar

Abra `index.html` no navegador. Os três arquivos devem permanecer juntos na mesma pasta. Não é necessário instalar nada.

## Como enviar ao GitHub

Crie um repositório e envie `index.html`, `styles.css` e `script.js` diretamente para a raiz. O arquivo `debug.log` é antigo e não faz parte do portfólio atual.
