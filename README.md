# Portfólio — Daniel Rocha Gonçalves

Código da página criada no Sites.

## Arquivos

- index.html: conteúdo, seções e links do portfólio.
- styles.css: cores, tipografia e layout responsivo.

## Como visualizar

Abra index.html no navegador. Não é necessário instalar dependências.
As fontes do Google Fonts precisam de conexão com a internet; caso indisponíveis, o navegador usa Arial.

## Como editar

Edite os textos e links em index.html e o visual em styles.css. Salve e atualize a página no navegador.
Alterações nesta cópia local não atualizam automaticamente a versão publicada no Sites.
